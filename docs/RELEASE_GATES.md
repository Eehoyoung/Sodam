## 7. N — 영구 Non-Goal (해소 대상이 아니다)

**"아직 안 함"이 아니라 "하지 않기로 한 것"이다.** 고도화 제안에도 포함하지 말 것.

### N-1 매입장부 (IDENTITY §8)
재고 수량 자동차감 · 원가율 · 메뉴마진 · POS 판매연동.
`ReorderHintScreen`의 "재고 자동 차감은 하지 않아요" 면책은 이 경계를 사용자에게 알리는 장치 — **제거·약화 금지**.

### N-2 개인 모드 (PRD §4.14)
개인 기록 기반 급여 계산·명세서 발급 · 근로계약·전자서명·4대보험 · 개인 근무지에 타인 초대 ·
홈택스/e-Tax 연계·복식부기 · **개인 모드 기록의 증명서 발급**(자기신고라 증명력 없음).

### N-3 법률상 불가
주민번호 저장 · 4대보험 EDI 신고 대행 · 세무/노무 대행 (개인정보보호법·노무사법·세무사법).
합법 대체(서식 자동작성·자료 집계)까지만.

### N-4 기획 단계에서 킬 판정된 것
급여 이체·지급 대행(통화불 원칙·자금이체업) · 매장 간 대타 **파견**(무허가 근로자공급, 형사처벌) ·
체불 사업장 공개·신고(명예훼손) · 세무사 소개수수료·기장료 셰어(세무사법 알선).

> ⚠️ N-4의 "세무사 소개수수료 폐기"는 **기장료 셰어·성공보수형에 대한 판정**이다.
> 현행 `TaxPackage`의 **정액 송객수수료 + 예수금 대리수취** 구조는 안전선으로 설계돼 살아 있다 — 흔들지 말 것.

## 9. 게이트를 해소했을 때

1. 이 문서의 해당 행을 **삭제하지 말고** 상태를 `해소(YYYY-MM-DD, 근거)`로 바꾼다 — 왜 막혀 있었는지가 나중에 더 중요하다
2. 코드 주석의 ID 참조를 함께 정리한다
3. 출시 차단(G·P)이 전부 해소돼야 스토어 배포·결제 라이브 전환이 가능하다
