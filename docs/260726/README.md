# 소담 사장님 웹서비스(Web Master Console) 개발 문서 세트

> 작성일: 2026-07-26 · 상태: 기획/설계 완료, **구현 미착수**
> 대상: 소담(Sodam) 모바일 앱의 사장(Master) 역할 전체 기능을 데스크톱 웹으로 신규 제공하는 "사장님 웹 콘솔" 프로젝트

## 0. 확정 조건 (사용자 결정 완료, 2026-07-26)

작업 착수 전 4가지 핵심 아키텍처 결정을 사용자에게 확인했고, 아래와 같이 확정되었다. 이후 모든 문서는 이 4가지를 전제로 작성됐다.

| 항목 | 결정 | 비고 |
|---|---|---|
| 프론트엔드 기술스택 | **자율 선정 위임** → Next.js(App Router) + TypeScript | "SaaS에 편리하고 보편적이며, 추후 AI 기능 추가 시 유지보수 용이한 스택"이라는 조건에 따라 선정. 근거는 [01_시스템아키텍처.md](01_시스템아키텍처.md) §2 |
| 기존 모바일 REST API 활용 | **하이브리드** — 공통 기능은 재사용, 웹 UX 최적화·서버부하 절감에 유리한 곳은 웹 전용 BFF 신설 | 초기 개발비용 증가 감수. 상세 분류는 [02_API_활용계획.md](02_API_활용계획.md) |
| 인증 방식 | **웹 전용 보안 배선 신설** — 세션/쿠키 기반, 기존 모바일 JWT와 분리 | 상세 설계는 [04_보안정책.md](04_보안정책.md) §1, 아키텍처는 [01_시스템아키텍처.md](01_시스템아키텍처.md) §4 |
| 1차 개발 범위 | **PRD.md §4 전체 기능** (4.1~4.12) | 단, 엔지니어링상 순차 구현이 필요해 Phase로 분할 — [08_개발로드맵.md](08_개발로드맵.md) |

### 0.1 2차 확인 (2026-07-26, 세부 결정 23건 확정)

각 문서에 남아있던 "확인 필요" 항목을 전량 재확인해 결정했다. 주요 결정만 요약하면: 매니저 웹 접근 1차 포함(전용 로그인 API 신설) · NFC는 목록조회/비활성화만 1차 · 도메인 `owner.sodam.app` · 낙관적 락은 append-only 로그성 엔티티를 제외한 전체(34종)에 적용 · Redis 분산 락/CSRF 모두 자체 구현 · Redis 세션 스토어는 초기 출시부터 HA(Sentinel/Cluster) · 배포는 기존 서버 컨테이너 추가(A안) + 모노레포 `web-master/` 디렉터리 · Toss Web SDK 계약 확인 전 착수 금지(TODO로 관리). 세부 근거는 각 문서 말미 "확정 (2026-07-26, 2차 확인)" 섹션 참고. **더 이상 남은 "확인 필요" 항목은 없다** (Toss SDK 건 제외 — 이는 미결이 아니라 "확인 전 착수 금지" 게이트).

## 2. 전제 및 참고 원본

- 기능 요건 원본: `docs/PRD.md` §4 (역할·퍼널·티어 게이팅·P0 기준 정의)
- 기존 백엔드: `backend/` Spring Boot 3.4.5 / Java 17, 포트 7070 고정
- 기존 규칙: `.claude/rules/api-design.md`, `.claude/rules/security.md`, `.claude/rules/testing.md`, `.claude/rules/frontend.md`
- **중요 발견**: `frontend/package.json`에 이미 `react-native-web` 기반 웹 빌드 스크립트(`build:web*`)가 존재한다. 이 문서 세트는 해당 기존 자산을 대체하는 것이 아니라, 사장 전용 데스크톱 콘솔이라는 별도 목적을 위한 신규 프로젝트로 판단했다 — 근거는 [01_시스템아키텍처.md](01_시스템아키텍처.md) §1.

## 3. 이 문서 세트의 성격

**순수 기획/설계 문서다. 코드 구현은 포함하지 않는다.** 각 문서는 결정 근거·선택지 비교·"확인 필요" 항목을 명시했다. 구현 착수 전 남은 미결 사항(배포 인프라 선택 등)은 각 문서의 "확인 필요" 섹션에 모아뒀다.

## 4. 노무사 게이트 관련 주의

`CONTRACT_MANAGE`·`PAYROLL_CONFIRM` 매니저 위임 권한은 `CLAUDE.md`에 명시된 대로 노무사 검토 미완료 상태다. 이 문서 세트에서 매니저 위임(§4.11) 웹 이식을 다루더라도, 위 2종 권한의 부여 흐름을 확장·개방·홍보하는 설계는 포함하지 않았다.
